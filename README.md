# VoiceScorer
VoiceScorer is a python program designed to be used for indoor cricket centres to transform audio input into scoring input.

## Requirements
- PyAutoGui
- VoiceRecognition
- PyAudio

## Use
Download and run script. It will automatically run in the background and enter score, press ctrl+c while in the command prompt window to force program to stop.

Made up of a rag-tag combination of copy-pasted code from other places on the internet, but it works so that's the solution

No need to select microphone (idk how to actually), it just uses default system microphone
